Run the weekly growth check for Backyard Brew and deliver a short ranked
action list.

## Do this

1. Read the `backyard-brew-brand` skill, `references/growth-playbook.md`, and
   `references/operations-reality.md`. The priority tiers are in the playbook.
   Do not recommend a tier 3 item while a tier 1 item is still broken.
2. **Ask before assuming.** A few short questions, not an interrogation:
   - How was last week? Which nights were busy, which were dead?
   - Anything change with staff, hours, or events?
   - Any new reviews, good or bad?
   - Did last week's actions actually get done?
3. If nothing has been tracked yet, say so and start the baseline this week
   rather than guessing at numbers.

## Deliver

**Three to five actions, ranked, each one small enough to finish this week.**
Not a strategy document. He is running a bar.

For each one:
- What to do, specifically
- Why it is on the list this week
- Roughly how long it takes
- Whether he needs to do it or can hand it to someone

Then one line: what to watch to know whether it worked.

## Rules

- **Foot traffic is the only real metric.** Reach that does not put people
  through the door does not count. Google Business Profile direction requests
  are the closest thing to a door counter.
- **Do not repeat last week's list.** If something did not get done, ask
  whether it is actually the right priority or whether it needs to be smaller.
- **Four weeks with no movement means change the approach**, not post harder.
- **Respect the crew size.** Anything requiring a dedicated person needs to
  say so up front, since it usually means hiring.
- Never recommend an event the bar already runs. Check the weekly table in
  `operations-reality.md` first.

## When asked for event ideas

If he asks something like "what would draw a crowd on Saturday," the built-out
concepts are already in `growth-playbook.md`, ranked, with what each one
needs. Use those rather than inventing something generic. Saturday daytime and
Sunday are the two windows that are actually empty. Tuesday and Wednesday do
not need new events, they need the right people to hear about the ones that
already exist.
