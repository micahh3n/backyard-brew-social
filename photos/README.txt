Drop your event photos in THIS folder.

Name them like this:
  YYYY-MM-DD_eventname.jpg              -> fresh photo for that day's "today" post
  YYYY-MM-DD_eventname_teaser.jpg       -> photo for the "tomorrow" teaser post
  YYYY-MM-DD_eventname_art.png          -> a finished graphic you designed (posted exactly as-is, no editing)

Examples:
  2026-07-13_bingo.jpg
  2026-07-13_bingo_teaser.jpg
  2026-07-13_bingo_art.png

If you don't drop a photo for a recurring event, the system falls back to the
default photo named in recurring_events.csv (e.g. bingo_default.jpg), which
should also live in this folder.

This README is just a note to you -- the system ignores it.
